## 🛠️ How to Host on GitHub Pages (Step-by-Step)

1. **Create a GitHub Repository**:
   - Repository name: `chirayukothari.github.io` (replace with your GitHub username if different).
   - Set visibility to **Public**.
2. **Upload Files**:
   - Drag and drop all files and folders (`index.html`, `research.html`, `publications.html`, `news.html`, `cv.html`, `css/`, `js/`, `images/`) into the repository.
   - Commit the changes.
3. **Enable GitHub Pages**:
   - Go to **Settings** &rarr; **Pages**.
   - Under **Build and deployment**, ensure **Source** is set to `Deploy from a branch` (Branch: `main`, folder: `/root`).
4. **View Live Site**:
   - Your website will be live in 1–2 minutes at `https://yourusername.github.io/`.
